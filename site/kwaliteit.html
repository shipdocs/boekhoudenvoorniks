Hoe wij BoekhoudenVoorNiks controleren

Je vertrouwt belangrijke financiële gegevens aan boekhoudsoftware toe. Daarom leggen we uit welke controles in de ontwikkeling zitten, en waar je zelf moet blijven opletten.

Boekingen met vaste regels

De boekhouding gebruikt vaste boekingsregels. Automatische tests controleren onder meer grootboeksaldi, debet en credit, btw-rubrieken, openstaande posten en dubbele verwerking.

Een vaste proefadministratie

Met een vaste set facturen, inkoopdocumenten en bankafschriften vergelijken we de uitkomsten met vooraf vastgelegde verwachtingen. Bij een afwijking moet eerst worden uitgezocht wat er veranderd is. De verwachte uitkomsten worden niet automatisch aan de software aangepast.

Controles voor een nieuwe versie

Bij pull requests draaien automatische controles op de rekenregels, de bouw van de app en de website-onderdelen. Daarnaast is er een beperkte browsertest voor belangrijke handelingen. Voor Windows en Linux zijn er afzonderlijke controles bij het publiceren van releases. Een geslaagde test bewijst dat de geteste scenario's werken, niet dat alle denkbare situaties zijn afgedekt.

Je gegevens blijven bij jou

De administratie staat standaard op je eigen computer. De app maakt back-ups en gebruikt externe koppelingen alleen wanneer je ze inschakelt. Een lokale administratie vraagt ook om eigen zorg: bewaar regelmatig een extra back-up op een andere veilige plek.

Wat deze controles niet betekenen

Deze controles zijn geen onafhankelijke accountantsverklaring, beveiligingscertificering of garantie dat iedere fiscale situatie correct wordt verwerkt. Controleer je gegevens en aangiften, zeker bij bijzondere transacties. Vraag zo nodig een boekhouder of belastingadviseur om advies.

Wie de technische details wil bekijken, kan terecht bij de testdocumentatie op GitHub en de wijzigingsgeschiedenis.
