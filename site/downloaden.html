Gratis downloaden

Download BoekhoudenVoorNiks voor Windows of Linux

Installeren, vijf vragen beantwoorden, eerste factuur maken. Gratis, zonder account, werkt offline en je administratie blijft op je eigen computer.

Windows

Windows 10 of 11, 64-bit

Geen Windows-waarschuwing, en nieuwe versies komen vanzelf via de Store.

De Store-versie is nog niet bijgewerkt naar 1.1.0. Wil je de nieuwste versie nu, gebruik dan de installer hieronder. Heb je het programma al met de installer van deze website? Wacht dan met overstappen tot de Store-versie ook 1.1.0 is: een oudere versie hoort een administratie van een nieuwere versie niet te openen.

Download voor Windows (.exe)

Windows kan de melding "Windows heeft uw pc beveiligd" tonen, omdat de installer nog niet met een betaald certificaat is ondertekend. Klik op Meer informatie en dan op Toch uitvoeren. Controlegetal: SHA-256.

Linux

64-bit (x86_64)

Download AppImage Download .deb

De AppImage werkt op de meeste distributies: geef het bestand rechten om uit te voeren (rechtsklik, Eigenschappen) en dubbelklik erop. De .deb is voor Debian, Ubuntu en Mint. Controlegetal: SHA-256.

Een versie voor Mac is er nog niet.

Na het installeren

  • Eerste start
    Beantwoord een paar vragen over je bedrijf. Daarna zie je op Vandaag wat er moet gebeuren. Wil je eerst rondkijken? Kies Bekijk de demo.
  • Je gegevens staan in een eigen map
    In de map BoekhoudenVoorNiks in je gebruikersmap, ook als je het programma verwijdert. Je kunt in Instellingen een andere map kiezen. Het programma maakt elke dag een back-up.
  • Nieuwe versies
    Het programma meldt zelf als er een nieuwe versie is. Voordat hij een nieuwe versie gebruikt, maakt hij eerst een kopie van je administratie.

Veilig downloaden

Download alleen van deze website (of uit de Microsoft Store). Wil je zeker weten dat het bestand niet is aangepast, vergelijk dan het SHA-256-controlegetal. In PowerShell: Get-FileHash .\BoekhoudenVoorNiks-Setup-….exe. De broncode is openbaar: BoekhoudenVoorNiks op GitHub.

Wat er per versie veranderd is, staat bij Wat is er nieuw. Controleer je btw-aangifte altijd zelf; zie de voorwaarden.
